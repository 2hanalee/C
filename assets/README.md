# 에셋 규격

| 종류 | 형식 | 크기 | 파일명 |
|---|---|---|---|
| 캐릭터 | 배경 투명 PNG | 긴 변 2000px 이상 | `assets/characters/<이름>/<이름>_<표정>_<각도>.png` (예: `리아_미소_3-4.png`) |
| 배경 | PNG 또는 JPG | 가로 1600px 이상 | `assets/backgrounds/<장소>_<시간대>.png` (예: `아카데미정문_낮.png`) |
| 로고 | 배경 투명 PNG 또는 SVG | 가로 1200px 이상 | `assets/logo/<작품명>.png` |

- 각도 표기: `정면`, `3-4`(3/4 측면), `측면`, `뒷모습`
- 첫 작업 전에 캐릭터별 **캐릭터 시트**를 제공한다: 정면 / 3-4 / 측면, 기본 표정 5종(무표정, 미소, 놀람, 분노, 슬픔)
- 한 장의 일러스트에 인물과 배경이 합쳐진 이미지도 쓸 수 있다. 이 경우 파일명에 `_full`을 붙인다(예: `리아_교실_full.png`). 레퍼런스의 상당수가 이런 통짜 일러스트를 크롭해서 컷으로 쓰는 방식이다.
- 에셋이 아직 없을 때 렌더러는 회색 실루엣 placeholder로 대체한다.
