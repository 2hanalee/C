# 문구 손질 기록 (11월 12일)

기준은 세 가지입니다.

1. 화면 안내 문구는 합니다체로, 주어와 서술어를 갖춘 문장으로 씁니다.
2. 기록 본문(장면, 연표, 문서, 장소)은 한다체 서술문으로 씁니다. 명사로 끝나는 조각 문장은 쓰지 않습니다.
3. 명사구는 칸 이름과 짧은 표지에만 씁니다. 문장 안의 가운뎃점(·) 나열은 "와/과"나 쉼표로 풉니다.
