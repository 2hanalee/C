## 확인하지 못한 것

- iOS Safari, 실제 안드로이드 기기
- Claude 아티팩트 안에서의 동작. 저장 창이 있을 때의 경로는 바꾸지 않았고, 저장 창 오류가 날 때만 새 다운로드 경로로 넘어갑니다.
- 아티팩트 샌드박스처럼 다운로드가 막힌 곳에서 링크가 동작하는지. 막혀도 이미지 표시와 JSON 글 상자는 그대로 남습니다.

참고: 테스트 컨테이너의 로케일이 UTF-8이 아니면 Chromium이 한글 파일 이름을 `download`로 바꿉니다. `LANG=C.UTF-8`에서는 `profile-card_일괄_2명.zip` 같은 이름이 그대로 나와, 도구의 문제가 아님을 확인했습니다.
