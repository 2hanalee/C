# 입장 연출 모션 그래픽 기획안

작성 11월 13일. 구현 전 기획이다. 참치가 방식과 스토리보드를 고른 뒤에 만든다.

**취소(11월 13일):** 참치 결정으로 모션 그래픽은 하지 않는다. WebGL 배경을 지우고, 입장 연출은 소리 없이 8초 안에 끝나는 글자 연출로 남겼다. 이 문서는 기록으로만 둔다.

**결정(11월 13일):** 하이브리드로 가되 소리는 넣지 않고, 단추가 나올 때까지 8초 안에 끝낸다. 8초짜리 고정 순서라 GSAP 없이 자체 시각표로 만들었다. 배경 그림이 오기 전까지는 WebGL로 그린 도시를 쓴다. 아래 표와 스토리보드의 소리 칸, 11초 시각표는 결정 전의 안이다.

결론: **하이브리드를 권한다.** 배경은 그림 한 장을 깊이 지도로 입체감 있게 움직이고, 빛과 정전은 WebGL 후처리로, 대사는 지금처럼 HTML 글자로 둔다. 전체 흐름은 타임라인 한 줄(GSAP)로 묶고, 소리는 합성음에 녹음 효과음 몇 개를 더한다. 영상 파일을 통째로 쓰는 방식보다 가볍고, 대사를 방문마다 바꿀 수 있으며, 글자가 선명하다.

## 1. 지금 입장 연출의 한계

지금 순서: 대사가 한 글자씩 켜짐 → 문양이 돎 → 전기가 튀며 정전 → 잔상 위로 로고. 효과는 Canvas 2D 입자와 CSS 빛, 소리는 브라우저 합성음이다.

| 부족한 점 | 원인 |
| --- | --- |
| 화면이 평평하다 | 배경이 단색 바탕과 입자뿐이고 공간이 없다 |
| 빛이 번지지 않는다 | CSS 그림자만으로는 블룸(밝은 곳이 주변으로 번지는 효과)을 낼 수 없다 |
| 정전이 「꺼짐」으로만 보인다 | 전기가 튀는 순간의 화면 왜곡(색 분리, 주사선, 깜빡임)이 없다 |
| 리듬이 소리와 따로 논다 | 글자, 효과, 소리가 각자 타이머로 움직인다 |
| 세계관이 안 보인다 | v3의 무대 인천과 「파스텔 포장 속 녹슨 톱니」가 화면에 없다 |

## 2. 세 가지 방식

| | ① 영상 파일 | ② 실시간 코드 고도화 | ③ 하이브리드 (권장) |
| --- | --- | --- | --- |
| 만드는 법 | 애프터 이펙트나 블렌더로 렌더해 WebM/MP4로 재생 | 지금 구조에 WebGL 후처리와 GSAP 타임라인을 더함 | 그림 한 장 + 깊이 지도 패럴랙스 + WebGL 후처리 + HTML 대사 + GSAP |
| 화질 상한 | 가장 높음 | 중간 | 높음 |
| 대사를 방문마다 바꾸기 | 어려움(대사마다 영상 한 편) | 쉬움 | 쉬움 |
| 글자 선명도 | 영상 압축으로 흐려짐 | 선명 | 선명 |
| 첫 화면까지 내려받을 양 | 10초 1080p에 약 4~8MB | 약 0.2MB | 약 1~1.5MB |
| 휴대폰 자동 재생 | 소리 없이만 가능 | 문제없음 | 문제없음 |
| 필요한 도구와 사람 | 모션 디자이너, 영상 도구 | 코드만 | 이미지 생성 1~2장 + 코드 |
| 고치기 | 다시 렌더 | 값만 바꿈 | 값만 바꿈, 배경은 그림 교체 |

①은 화질이 가장 좋지만, 대사를 바꿀 때마다 다시 렌더해야 하고 휴대폰에서 무겁다. ②는 가볍지만 그림이 없어 공간감에 한계가 있다. ③은 그림이 공간을 맡고 코드가 빛과 시간을 맡아서, 무게는 ②에 가깝고 화질은 ①에 가깝다.

## 3. 스토리보드 (약 11초, 건너뛰기는 언제나 가능)

모티프: v3 침식 1단계 「그림자가 반 박자 늦게 따라온다」와 연출 규칙 「반짝이던 변신 이펙트가 반 박자 늦게 따라온다」. 정전 순간에 파스텔 불빛만 **반 박자 늦게** 꺼지게 해, 이 세계의 침식을 모션의 문법으로 쓴다.

| 시각 | 화면 | 소리 |
| --- | --- | --- |
| 0.0초 | 완전한 어둠. 아주 옅은 필름 입자 | 형광등이 웅웅거리는 저음 |
| 0.6초 | 밤의 인천이 천천히 드러남. 왼쪽은 송도의 파스텔 타워와 랭킹 전광판, 오른쪽은 내항의 녹슨 크레인. 깊이 지도로 카메라가 아주 느리게 앞으로 감 | 먼 항구의 바람 |
| 1.8초 | 대사가 한 글자씩 켜짐. 글자마다 빛이 번지고(블룸), 도시 불빛이 글자 리듬에 맞춰 미세하게 흔들림 | 글자마다 종소리(지금 것 유지) |
| 6.0초 | 대사 완성. 하늘에 가는 균열 선이 그어지고 문양이 한 바퀴 돎 | 낮은 금속성 울림 |
| 7.4초 | 전기가 튐: 색 분리, 주사선, 화면이 두 번 깜빡임. 녹 구역 불빛이 구역별로 꺼짐 | 전기가 튀는 소리 두 번 |
| 7.9초 | 송도의 파스텔 불빛과 전광판이 **반 박자 늦게** 꺼짐. 전광판의 「구조율 92%」가 마지막에 꺼짐 | 「툭」, 이어서 무음 |
| 8.4초 | 무음 0.6초. 대사의 잔상만 망막처럼 남음 | 무음 |
| 9.0초 | 잔상 위로 BLACKOUT 로고가 필라멘트처럼 점등 | 필라멘트가 데워지는 소리 |
| 10.5초 | 「기록 열람」, 「다시 보기」 단추 | 없음 |

다시 방문하면 지금처럼 9.0초(로고)부터 시작한다.

## 4. 기술 구성

- **타임라인:** GSAP 3 한 줄에 글자, 효과, 소리를 모두 건다. 대사의 호흡값(beats)은 지금 데이터를 그대로 쓴다. GSAP은 3.13부터 모든 플러그인이 무료다. 정확한 버전은 구현할 때 고정한다.
- **배경 그림:** 이미지 생성으로 「밤의 인천, 왼쪽 파스텔 타워, 오른쪽 녹슨 항구」 16:9 한 장. 같은 그림의 깊이 지도(흑백) 한 장. 불빛만 따로 뽑은 마스크 한 장(정전 때 구역별로 끄는 데 씀). 세 장 모두 WebP, 합계 약 1MB.
- **후처리:** WebGL 셰이더 하나에 블룸, 색 분리, 주사선, 필름 입자, 비네트를 넣는다. three.js 같은 큰 라이브러리 없이 셰이더 하나로 만들면 약 15KB다.
- **글자:** 대사는 지금처럼 HTML 글자(빛의계승자체)로 둔다. 화면 읽기 프로그램이 읽을 수 있고, 대사를 방문마다 바꿀 수 있다. WebGL은 글자 뒤의 빛만 맡는다.
- **소리:** 합성음은 유지한다. 전기 튐, 「툭」, 필라멘트 세 가지만 짧은 녹음 효과음(합계 100KB 아래)으로 바꾼다. 화면을 한 번 눌러야 켜지는 규칙은 그대로다.

## 5. 품질 기준과 성능 예산

| 항목 | 기준 |
| --- | --- |
| 첫 글자가 켜지기까지 | 1초 안. 배경은 늦게 와도 글자는 먼저 시작 |
| 내려받을 양 | 1.5MB 아래(배경 그림 포함) |
| 프레임 | 휴대폰 중급 기종에서 60fps, 못 맞추면 후처리를 줄임 |
| 기기 단계 | 상: 전체 / 중: 블룸만 / 하(WebGL 없음, 절전 모드): 지금 연출 |
| 모션 줄이기 설정 | 움직임 없이 대사와 로고만 페이드 |
| 건너뛰기 | 처음부터 끝까지 언제나 누를 수 있음 |
| 가로 넘침, 콘솔 오류 | 0 |

## 6. 진행 순서

1. 스토리보드 승인: 위 표를 참치가 고친다.
2. 배경 그림 세 장: 이미지 생성 프롬프트를 `docs/image-prompts.md`에 추가하고, 참치가 만든다.
3. 시제품: 브랜치에서 만들고 미리보기 아티팩트로 보여 준다. 기존 연출은 하(下) 단계로 남긴다.
4. 점검: 기존 점검 스크립트에 프레임 측정과 내려받을 양 측정을 더한다.

## 7. 확인할 것

- 빛의계승자체를 영상에 렌더해도 되는지는 ①을 고를 때만 문제가 된다. 권장안 ③은 글자를 HTML로 그리므로 지금과 같다.
- 배경 그림의 송도와 내항은 실제 지명이다. 실제 건물을 그대로 그리지 않고 분위기만 따른다.
