# 통합 설정집 v3 반영 기획안

작성 11월 13일. 기준 문서: 「마법소녀 세계관 통합 설정집 v3」(11월 13일, rev 229). 구현은 참치가 후보를 고른 뒤에 한다.

결론: **후보 B(구획 재배치)를 권한다.** v3의 핵심 변화는 무대(하란 → 인천), 세계 규칙(침식 5단계, 이름의 값), 중심 음모(예고 장부)라서 데이터만 바꾸는 A로는 새 설정이 들어갈 자리가 없다. B는 세계관 문서를 다시 짜고, 인물 카드에 대화 시작점(훅, 자주 벌어지는 일, 말투)을 더한다. 일은 세 단계로 나눠 첫 단계만 끝나도 사이트가 v3와 어긋나지 않게 한다.

먼저 정해야 할 것: v3의 ◇는 「제안」이 아니라 「이번 통합에서 새로 정한 설정, 나중에 바꿀 수 있음」이다. 지금 규칙(◇는 싣지 않음)을 그대로 쓰면 예고 장부, 이름의 값, 침식 5단계의 사건 다섯 건, 아카데미 캠퍼스 위치, 안개고개 위치가 모두 빠진다. 이 표의 등급은 ◇를 싣는다고 보고 매겼고, ◇ 항목에는 따로 표시했다.

**비밀·운용 메모의 처리.** 메모에는 두 가지가 섞여 있다. 인물이 먼저 꺼내지 않는 진실(예: 레이나의 승리 상당수가 예고된 전투였다)은 그 인물의 기밀 기록으로 싣는다. 연기 기준(예: 「광인이 아니라 … 연기한다」), 능력 분류 A·B·C, 이야기 후반의 반전(임시 봉합이 왕의 설계였다)은 사이트에 싣지 않는다.

**설정 원문.** 인물 소개문, 능력, 관계, 가려진 기록의 문장은 v3에 맞춰 새로 옮겨야 한다. 49인 전원의 전후 대조표를 만들어 승인받은 뒤에 바꾼다.

## 3. 기획안 후보

### 후보 A. 최소 반영: 데이터만 갱신

한 줄 콘셉트: 화면 구조는 그대로 두고, 이름과 숫자와 문장을 v3에 맞춘다.

정보 구조 변화: 없음. 페이지 5개, 세계관 문서 8건, 메뉴가 그대로다. 새 설정(침식 5단계, 예고 장부, 이름의 값)은 기존 문서의 한 구획이나 기밀 기록으로 끼워 넣는다.

주요 화면:

```
[세계관 02 이계의 법과 침식]          [지도]
 침식 / 법의 부스러기 / 마모          인천 약도(새로 그림)
 + 새 구획 「침식의 5단계」(표)        핀 9개 → 11개
 가려진 기록: 이름의 값(내부)          (부평, 북항, 신포동, 월미도, 만석동 …)
```

고치는 파일: characters.js, world.js, timeline.js, quotes.js, index.html, timeline-page.js(지도), 각 HTML 설명문. 작업량: **중간**.

위험과 단점: 예고 장부가 문서 여덟 건에 흩어져 기밀로만 들어가 전체 그림이 보이지 않는다. 문서 제목과 v3의 목차가 어긋난다. 인물 카드가 대화 시작점(훅, 자주 벌어지는 일)을 담지 못한다.

사용자 체감: 지명과 인물만 바뀐다. 처음 보는 사람은 차이를 거의 못 느낀다.

### 후보 B. 구획 재배치: 문서 재편과 인물 카드 확장 (권장)

한 줄 콘셉트: v3의 목차를 따라 세계관 문서를 다시 짜고, 인물 카드를 「대화를 시작하는 카드」로 바꾼다.

정보 구조 변화:

- 세계관 문서 8건 → 10건. 01 칠월의 밤 / 02 인천: 파스텔과 녹 / 03 이계의 법: 침식, 마모, 이름 / 04 침식의 5단계 / 05 왕과 칠좌(거울 표 포함) / 06 회색 구역과 이계 생물 / 07 방위청, 아카데미, 랭킹 / 08 기업 연합과 에이전시 / 09 휴전기 / 10 임시 봉합.
- 예고 장부는 문서로 세우지 않는다. 흩어진 은폐가 하나의 장부에서 나왔다는 것이 v3의 구조이므로, 사이트도 장부의 조각을 문서와 인물의 기밀 기록에 흩어 둔다. 기밀을 여러 개 연 사람만 그림을 맞출 수 있다.
- 인물 카드 상세에 칸 3개를 더한다: 훅(카드 맨 위 한 줄), 자주 벌어지는 일(대화를 시작할 장면 2~3개), 말투(한 줄 설명과 예문).
- 메인 「네 장면」은 그대로 네 장면이되, 셋째와 넷째를 v3의 사건으로 바꿀지 검토한다(예: 안개고개 → 지하상가 사건). 메인 순위표는 v3 표를 따른다.
- 지도는 인천 약도와 한반도 작은 지도 두 장으로 나눈다. 핀에 침식 단계를 표시한다.

주요 화면:

```

 │ "모든 학생의 생일과 약점을 외우는 학생위원장 —   │  ← 훅
 │  그녀는 2년째 선배의 사물함을 비우지 못한다."     │
 │ [사진 3:2]        2  레이나 드 로즈             │
 │ [표정 7]          구분 / 소속 / 직위 / 성격       │
```

## 5. 참치가 정할 것

1. **◇ 항목을 실을까요?** v3의 ◇는 「새로 정했고 바뀔 수 있음」입니다. 싣지 않으면 예고 장부, 이름의 값, 침식 사건 다섯 건, 캠퍼스와 안개고개 위치가 빠집니다. 제안: 싣되, 바뀔 수 있는 항목은 데이터에 표시해 두고 한 번에 고칠 수 있게 합니다.
2. **후보를 골라 주세요.** 권장은 B이며, 1단계(정합)부터 시작합니다.
3. **가칭 인물과 삭제 인물.** 류서경과 온새별은 가칭이고, 권도하는 능력이 없는 전사자입니다. 셋 다 인물 카드로 실을지, 이아름과 마리아 오르텐의 삭제를 확정할지 정해 주세요. 제안: 셋 다 싣고, 가칭은 이름이 정해지면 바꿉니다. 권도하 카드는 사진 대신 「전사」 도장을 찍습니다.
