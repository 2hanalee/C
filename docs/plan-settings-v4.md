# 「캐릭터 설정 통합 정리본」 사이트 적용 기획안

작성 11월 23일. 기준 문서: `docs/source/settings-integrated.md`(참치가 준 「마법소녀 세계관 — 캐릭터 설정 통합 정리본」 원문, 이하 정리본).

## 결론

정리본을 사이트의 **유일한 기준**으로 삼는다. 지금 사이트는 설정집 v3를 기준으로 만들어졌는데, 정리본과 v3는 세계의 뼈대부터 다르다. 그래서 이번 작업은 고치기보다 **다시 쓰기**에 가깝다.

- 정리본에 있는 것: 정리본대로 다시 쓴다.
- 정리본에 없고 사이트에만 있는 것: 아래 7장 목록으로 확인받은 뒤 **전부 지운다**.
- 지울 것(참치 지시): 말투 기호(♡ ♧ ♤), 공용 능력계열 기호(○ ● ◇ □ ■ ☆ ★ △ ◐).
- 정리본 안에서도 **유의미한 것만** 싣는다. 기준은 2장.

화면 구조(인사기록카드, 먹칠, 가려진 기록, 메뉴, 입장 연출, 음악)와 그림은 설정이 아니므로 유지한다.

## 2. 「유의미한 것만」의 기준

정리본은 작가용 설계 문서라 사이트 독자에게 필요 없는 문장이 섞여 있다. 아래는 싣지 않는다.

| 싣지 않는 것 | 예 | 이유 |
| --- | --- | --- |
| 말투 기호, 능력계열 기호 | `♧`, `○ □ ☆ ★` | 참치 지시 |
| 캐릭터 코드 | MG01, AV03, SE06 | 내부 관리 번호. 본문의 「(MG11)」 같은 괄호 표기도 이름으로 바꾸거나 뺀다 |
| 문서 운영 문장 | 문서 목적, 문서 구성, 빠른 목차, 문서 상태, 이미지 프롬프트 관련 문장 | 설정이 아님 |
| 모티프·참고작 | 「모티프: 루시퍼 계열 + 벨리알」, 「모티브 캐릭터: 할리퀸」, 『원펀맨』, 오리온즈 암 | 창작 참고 정보. 세계 안의 사실이 아님 |
| 작가용 해설 | 「서사 기능」, 「추천 도입부 구성」, 「설정 일관성 체크리스트」, 비고의 연출 지침(「~로 다룬다」, 「~로 활용한다」, 「미화하지 않는다」 등) | 세계 안의 사실이 아니라 쓰는 법 |
| 제안 단계 항목 | 네이사가 기습한 이유 후보 세 가지 | 정리본이 「확정 전까지 제안」으로 분류 |
| 「(미정)」 칸 | 아델리아의 능력·말투·대사, AV02의 대부분 | 빈 칸은 화면에 그리지 않는다 |
| 신체 치수 외의 체형 묘사 | 표의 「체형·가슴」 칸, 「글래머 체형」, 「중간 정도의 가슴」 | 인사기록카드에 필요 없는 묘사. 키, 머리, 눈, 옷차림, 상징물만 싣는다 (확인 필요: 7장 G) |

**싣는 것:** 세계 안의 사실(설정, 제도, 사건, 관계), 인물의 외형·성격·말투·과거·능력·대표 대사, 그리고 비고 가운데 세계 안의 사실인 문장(예: 「인터넷 닉네임은 clip_clover」, 「빌리온은 원래 인간 병사였다」).

## 4. 인물 카드 칸 대응

| 정리본 | 사이트 칸 | 처리 |
| --- | --- | --- |
| 활동명 / 본명 | 활동명(alias) / 이름(name) | 그대로 |
| 진영·역할 | 직위(role), 랭킹(rank), 소속(faction) | 「/」로 나뉜 항목을 칸에 나눠 넣는다 |
| 핵심 키워드(요약표) | 성격 태그(traits) | 메인 25인은 요약표 키워드, 나머지는 성격 문단의 핵심어 |
| 고유능력명 + 능력설명 | 능력 이름, 능력 설명, 한계 | 「~하지 못한다」, 「~에서는 약하다」처럼 제약을 말하는 문장은 「한계」로 옮긴다. 문장은 고치지 않는다 |
| 왕의 패시브(칠좌) | 능력 칸 아래 「왕의 패시브」 | 새 칸 |
| 외형 | **새 칸 「외형」** | 체형·가슴 묘사는 빼고 싣는다(2장) |
| 성격 | **새 칸 「성격」** | 그대로 |
| 말투 | 「말투」 | 기호를 빼고, 말투 이름과 설명을 싣는다 |
| 대표 대사 | 카드 위쪽 인용문(quote) | 지금의 카드 인용문(「오늘도 평안한 하루가 되시기를♡」 등)을 대신한다 |
| 관계·서사 / 과거(칠좌) | 「과거」 | v3 인물 문단 대신 정리본 문장을 싣는다. 가릴 문장은 지금처럼 먹칠 |
| 현재·악행, 목표, 잠입 임무(칠좌) | **새 칸 「지금」** | 칠좌와 왕만 해당 |
| 비고 | 성격·과거·가려진 기록 가운데 맞는 곳 | 세계 안의 사실만. 연출 지침은 뺀다 |
| (정리본에 없음) 개요 | 개요 | 정리본 문장으로 한 문장 요약을 새로 쓴다. 목록 카드와 메인에 필요하다 |
| (정리본에 없음) 관계 단추 | 관계 | 정리본 본문과 「핵심 대립축」에 나오는 연결만 남긴다 |
| (정리본에 없음) 훅, 자주 벌어지는 일, 하위 기술, 말투 예문, 등수 변동(▲▼) | — | **삭제 후보**(7장 B) |
| 그림, 서명 색, 표정 그림 자리 | 그대로 | 설정이 아님 |

상세 화면 순서(제안): 개요 → 성격 → 과거 → (칠좌) 지금 → 능력 → 외형 → 말투 → 관계 → 가려진 기록.

## 5. 가려진 기록(내부용·기밀) 다시 매기기

정리본에는 등급 표시가 없다. 지금의 72건은 v3 사실이라 대부분 사라진다. 참치가 지난번에 가려진 정보를 줄이라고 했으므로, 정리본이 **세계 안에서 숨겨져 있다고 명시한 것만** 가린다.

- 기밀: 「공식 기록에 남아 있지 않다」, 「초반에 공개하지 않는다」, 「본인은 모른다」, 「알지 못한다」, 「진상」으로 적힌 사실.
- 내부용: 아카데미 안이나 가까운 사람만 아는 사실(내부 논쟁, 기록의 수정 흔적, 본인만 아는 습관의 이유).
- 그 밖에는 공개. 성격 칸의 「실제로는 냉담한 계산가」처럼 정리본이 인물 소개에 드러내 둔 성격은 가리지 않는다.

1차 후보(약 16건, 다음 작업에서 문장을 확정한다):

| 등급 | 인물 | 사실 |
| --- | --- | --- |
| 기밀 | 정하은·셀레스티스 | 전쟁 당시 직접 대면했고, 그 내용은 공식 기록에 없다 |
| 기밀 | 천시온·도연화 | 천시온은 이계인에 가까운 존재이며 셀레스티스와 오래된 관계이고, 도연화의 「미지의 스승」이다 |
| 기밀 | 아델리아·네이사·엘리제·라그바르 | 아델리아는 라그바르를 이긴 직후 네이사의 기습으로 죽었고, 네이사가 그 몸을 쓰고 있다 |
| 내부용 | 아델리아 | 칠왕정 첩보 임무 중 사망했다(공개는 「5위 사망」뿐) |
| 기밀 | 신유안·메르칸·레이나 | 신유안이 레이나를 살리는 값으로 메르칸과 계약했고, 레이나는 침묵했다 |
| 기밀 | 이아름·차유리·박시온 | 이아름의 양부모는 칠왕정의 핵심 인물이다 |
| 내부용 | 차유리 | 이아름의 생체 정보에서 이상을 발견했다 |
| 기밀 | 빌리온 | 원래 전장에서 크게 다친 인간 병사였고 기억이 포맷되었다 |
| 내부용 | 노아 | 제작 기록에서 기동일이 두 번 수정된 흔적이 있다 |
| 기밀 | 이벨린 | 성검의 힘이 쓰일 때마다 기억이 지워지고, 이를 엘리제에게 숨긴다 |
| 기밀 | 장유라 | 아카데미가 그녀의 영역을 불법 구금과 고문에 쓰려 한 기록이 있다 |
| 내부용 | 유채린·레인 | 「별이 떨어진 밤」에 채린을 구한 「여신의 사자」는 레인 스타폴이다 |
| 기밀 | 유하람 | 방송 기록이 레이나의 배신을 증명할 증거가 된다 |
| 기밀 | 미즈노 사키 | 훔친 기록으로 중요한 증거를 손에 넣는다 |
