# 기능 명세 및 구현 계획 (0단계 산출물)

작성일: 2026-11-14 · 상태: **0단계 승인됨, 1단계 보강 완료** (7절: 사용자 답변 반영)

## 1. 목적과 성공 기준

**목적**: AI 캐릭터 채팅의 세계관 소개와 도입부를 세로 스크롤 웹툰으로 만든다. 독자(= 채팅 유저)가 웹툰을 다 읽은 직후 첫 채팅을 시작하고 싶어지게 하는 것이 목표다.

**성공 기준 (MVP)**
1. 장면 설명 1개를 넣으면 다음이 차례로 나온다: 장면 해석 → 콘티(표+JSON) → 에셋 요청서 → 렌더링 PNG
2. 결과물이 레퍼런스와 같은 규격(가로 1000px, 장당 세로 최대 8000px)으로 나온다.
3. 품질 체크리스트(`knowledge/directing-rules.md` 10절)를 자동·수동으로 통과한다.
4. 콘티 JSON만 고치면 다시 렌더링된다. 그림 작업은 다시 할 필요가 없다.

## 2. 확정한 결정 사항

| 항목 | 결정 | 근거 |
|---|---|---|
| 툴 형태 | Claude Code 스킬(`/webtoon-scene`)과 Node.js 렌더링 스크립트 | 사용자 지정 |
| 캔버스 | 가로 1000px, PNG 분할 높이 최대 8000px | 원본 해상도로 보이는 레퍼런스 6개 작품 25장이 모두 가로 1000px, 대부분 세로 8000px 분할 (reference-analysis.md 1절) |
| 렌더링 | HTML/CSS 템플릿 → Playwright 스크린샷 → 8000px 단위 분할 | Claude가 가장 안정적으로 다루는 시각화 방식. 폰트, 마스크, 그라데이션을 CSS로 처리한다. |
| 중간 산출물 | 콘티 JSON(스키마 검증) | 텍스트 단계에서 연출을 확정한 뒤 렌더링하므로 수정 비용이 낮다. |
| 기본 구조 | "AI 채팅 도입부 6비트 골격"(reference-analysis.md 3절)을 기본 템플릿으로 제공한다. | 레퍼런스 10개 폴더의 공통 구조 |
| 분량 | 1000×8000 PNG **2~4장**(16,000~32,000px) | 사용자 확정 |
| 시점 | **"당신은"으로 시작하는 2인칭**, 유저 = 주인공 | 사용자 확정. 레퍼런스 10개 폴더 모두 독자를 주인공 자리에 놓음(2인칭 호명 7, 1인칭 주인공 시점 3) |
| 연출 기준작 | **탐정 아카데미 19th, StartRail** → 혼합형 구성(StartRail식 2인칭 나레이션으로 열고 닫고, 가운데는 탐정 아카데미식 캐릭터 만담) | 사용자 지정, reference-analysis.md 5절 |
| 폰트 | 무료·상업 이용 가능 폰트(OFL 등)만 쓴다. 후보: Noto Serif KR, Gowun Batang, Noto Sans KR, Black Han Sans, Nanum Pen Script | 라이선스 리스크 회피 (최종 선택은 2단계) |
| 그림 | Claude는 그리지 않는다. 사용자 에셋을 합성만 한다. | 역할 경계 |

## 3. 범위

**MVP에 포함**
- 1장면(4~12컷 + 나레이션) 처리
- 렌더러 요소 카탈로그(아래 3.1)의 핵심 요소
- 에셋 placeholder(회색 실루엣)
- 자동 검사: 말풍선 글자 수/줄 수, 최소 글자 크기, 요소 겹침, 이미지 누락

**MVP에서 제외 (이후 확장)**
- 여러 장면을 이어 붙인 회차 단위 편집기
- 이미지 생성 AI 연동
- 애니메이션(GIF/모션) 컷
- GUI 편집 화면

### 3.1 렌더러 요소 카탈로그 (레퍼런스에서 추출)

| 분류 | 요소 | 레퍼런스 예 |
|---|---|---|
| 컷 | 직사각 컷(전폭/인셋), 사선 컷, 붓터치 마스크 컷, 삼각 파편 몽타주, 흐림·투명도 컷(회상), 좌우 엇갈림 소형 컷 | StartRail, Reise, Lonely Madman |
| 텍스트 박스 | 나레이션 박스(흰 바탕/검은 바탕, 얇은 테두리), 장소·시간 캡션, 네임플레이트(`[직함] 이름`, `소속 <이름>`) | 전 작품 |
| 말풍선 | 타원(꼬리 있음/없음), 외침(가시형), 검은 말풍선(위압·냉소), 흐림 말풍선(배경 잡담), 시스템 육각 박스, 속마음 | Lonely Madman, 탐정 아카데미, 퇴장빌런 |
| 타이포 | 대형 강조 문구, 붉은 경고 문구, 발광 텍스트, 세로쓰기 문구, 손글씨 효과음 | Reise, StartRail, 퇴장빌런, 아카데미 이야기 |
| 전환 | 흰→검 그라데이션, 검→흰 그라데이션(눈뜸), 여백 스페이서 | Infereno, Reise |
| 마감 | 타이틀 로고 + 태그라인 카드, 선택·초대 문구 | 전 작품 |

## 4. 작업 흐름과 승인 지점

```
[1회] 0 범위 확정 ──▶ 1 지식 구축 ──▶ 2 스타일·캐릭터 등록
[장면마다]
  3 장면 해석 ▶승인 → 4 콘티(표+JSON) ▶승인 → 5 에셋 요청서
  → 6 렌더링 → 7 자체 검수(체크리스트 + 스크린샷 확인) → 1회 수정 ▶승인
```

```
  style-sheet.md              (2단계) 이 작품의 폰트·색·말풍선 스타일
  world-bible.md              (2단계) 세계관·캐릭터 바이블

assets/                       사용자 에셋 (규격: assets/README.md)
schema/storyboard.schema.json (3단계) 콘티 스키마
renderer/                     (5단계) render.mjs, templates/, components.css
episodes/<작품>/<장면>/        brief.md, storyboard.json, asset-request.md
output/                       렌더링 결과 (git 제외)
.claude/skills/webtoon-scene/ (6단계) 반복 작업 스킬
```
