## 3. 공통 구조: "AI 채팅 도입부 6비트 골격"

10개 폴더에서 거의 공통으로 나타나는 흐름이다. 도입부 템플릿의 기본값으로 쓴다.

| 비트 | 역할 | 관찰된 기법 | 예 |
|---|---|---|---|
| ① 콜드 오픈 | 첫 화면에서 질문이나 감정을 던진다 | 넓은 여백 위 대형 타이포 한 줄 | Reise "어때?", StartRail "청춘(靑春)", Infereno "....도와줘.", Lonely Madman "진행상황 보고." |
| ② 세계관 브리핑 | 세계의 규칙과 배경을 전달한다 | 나레이션 박스 1개 = 정보 1개, 풍경 와이드 컷, 지도·인포그래픽 | 고교전쟁 서울 지도, 단편 26구역 지도, 마법소녀 공진 연대기, 霜刃行 전쟁 |
| ③ 위협·결핍 | 세계의 문제와 긴장을 제시한다 | 흰→검 그라데이션 전환, **붉은 문구**, 어두운 색조 | Reise "그것들 전부가 해피엔딩일순 없어.", 마법소녀 "살아있는 폭탄" |
| ④ 캐릭터 소개 | 채팅 상대가 될 캐릭터를 각인시킨다 | 네임플레이트 캡션(`[직함] 이름`, `소속 <이름>`), 캐릭터별 대사 1~2개, 세력 소개 반복 패턴 | 탐정 아카데미 "아카데미 소속 탐정 <롤랑>", 아카데미 이야기 "[제1왕녀] 아이린" |
| ⑤ 유저 자리 만들기 | 독자를 주인공 위치에 놓는다 | 2인칭 호명(너/당신/자네), 1인칭 시점 컷(손, 발, 눈뜸), 캐릭터가 화면 밖 유저에게 말 걸기 | Infereno 검은 화면 속 목소리 → 눈뜸, 아카데미 이야기 입학 증서를 든 손 |
| ⑥ 초대·타이틀 | 채팅 시작으로 넘긴다 | 선택·초대 문구 → 타이틀 로고 + 영문·한자 태그라인 | "결말은 너가 정하는거야.", "당신은 과연 어떤 선택을 할 것인가?", "그럼 시작하지, 우리의.. 그리고 자네의.", "지금! 당신의 역할을 선택하세요!" |

- 시점: 10개 폴더 모두 독자를 주인공 자리에 놓는다. 2인칭 호명이 7개(Reise, StartRail, 고교전쟁, 마법소녀, 탐정 아카데미, 단편, Lonely Madman)이고, 1인칭 주인공 시점이 3개(Infereno, 아카데미 이야기, 퇴장빌런)다. 마법소녀와 Lonely Madman은 호명 대상이 유저라는 것이 추정이다.
- 비트 순서는 작품마다 조금씩 다르다. 캐릭터 중심 작품(Infereno, 탐정 아카데미)은 ②를 짧게 하고 ④⑤를 길게 한다. 세계관 중심 작품(고교전쟁, 마법소녀, 단편)은 ②③이 대부분을 차지한다.

## 4. 연출 기법 카탈로그

### 4.1 컷 형태
- **전폭 직사각 컷**: 풍경, 세계관 소개 (Reise, 마법소녀)
- **사선 컷**: 감정이 흔들리는 순간, 청춘물의 역동성 (StartRail)
- **붓터치 마스크 컷**: 여러 지역을 가볍게 훑을 때. 테두리 없이 흰 배경에 녹아든다 (Reise 지역 소개)
- **삼각 파편 몽타주**: 등장 캐릭터를 한꺼번에 예고 (StartRail 엔딩 직전)
- **얇은 띠 컷(가로로 긴 클로즈업)**: 눈, 입, 손 같은 디테일. 긴장 고조 (Infereno, Lonely Madman, StartRail)
- **흐림·반투명 컷**: 회상, 꿈, 희미한 기억 (Infereno 페이드 컷)
- **좌우 엇갈림 소형 컷**: 빠른 대화 교환, 시선 왕복 (Lonely Madman)

### 4.2 텍스트 요소
- **나레이션 박스**: 흰 바탕+검은 테두리(밝은 장면), 검은 바탕+흰 테두리(어두운 장면). 1박스 1~3줄이다. 좌·우·중앙을 번갈아 배치해 시선을 지그재그로 끈다.
- **박스를 컷 경계에 걸치기**: 나레이션이 다음 이미지를 "소개"하는 효과 (Reise, Infereno, 마법소녀)
- **네임플레이트**: 캐릭터 첫 등장 컷의 아래쪽이나 옆에 붙인다. 형식은 `[직함] 이름` 또는 `소속 직함 <이름>`이다.
- **장소·시간 캡션**: 장면 첫 컷 상단에 둔다 ("1900년 XX월 XX일 영국 런던.", "2032년, 서울", "[벨제 가문 저택]").
- **대형 타이포**: 콜드 오픈, 테마 선언, 엔딩 직전의 결정적 한 줄. 이미지 없이 여백 위에 단독 배치한다.
- **색 문구**: 붉은색은 위협·불길함, 발광 흰색은 결의·희망 (Reise, StartRail).
- **세로쓰기**: 장소 이름을 신비롭게 보여줄 때 (퇴장빌런 "여기— 루베른 거울호수").

### 4.3 말풍선 변주 (Lonely Madman, 탐정 아카데미가 가장 풍부)
- 타원+짧은 꼬리: 기본 대사
- 꼬리 없는 타원(여백에 떠 있음): 화면 밖 목소리, 장면 사이 대사
- **가시형(외침)**: 큰 소리, 놀람. 글자도 키운다.
- **검은 말풍선(흰 글씨)**: 위압, 냉소, 속내
- **흐림 말풍선**: 배경 잡담. 내용보다 "웅성거림"을 전달한다.
- **육각 시스템 박스**: 게임, 시스템, 공적인 선언 (퇴장빌런)
- 모든 대사를 “ ” 따옴표로 감싸는 스타일이 Reise, Lonely Madman, 탐정 아카데미에서 일관되게 쓰인다.

### 4.4 전환과 호흡
- **흰→검 그라데이션(약 600~1500px)**: 밝은 소개 → 어두운 진실로 넘어갈 때
- **검→흰 그라데이션**: 의식이 돌아옴, 눈뜸, 희망 (Infereno 기상 장면)
- **연속된 짧은 나레이션 + 넓은 여백**: 독자의 스크롤 속도를 늦추고 한 줄씩 곱씹게 한다 (StartRail, 霜刃行)
- **"하지만." 단독 박스**: 반전 직전에 여백 위에 홀로 두어 멈칫하게 한다 (StartRail, 마법소녀)

### 4.5 엔딩 카드
- 마지막 초대 문구 → 넓은 여백 → 로고(중앙) → 태그라인(영문 또는 한자 병기). 예: "“I'm still standing here for you.”", "“서리 낀 칼날의 여정.”"
- 로고 뒤에 짧은 부제를 덧붙이기도 한다 ("시작의 이야기.", "징계위원회 출석까지. D-4.").

## 5. 연출 기준작 정밀 분석 (사용자 지정: 탐정 아카데미 19th, StartRail)

두 작품은 접근이 정반대다. **탐정 아카데미는 "대사로 세계를 보여주는" 캐릭터 만담형**이고, **StartRail은 "나레이션으로 테마를 선언하는" 에세이형**이다. 우리 작품은 "당신은"으로 시작하므로, StartRail의 2인칭 나레이션으로 열고 탐정 아카데미의 캐릭터 만담으로 세계를 보여주는 **혼합형**을 기본으로 제안한다(5.3).

### 5.1 탐정 아카데미 19th (4장, 1000×8000, 밤·검정 배경)

| 구간 | 내용 | 기법 |
|---|---|---|
| 1장 앞 | 검은 여백 → "1900년 XX월 XX일 영국 런던." 캡션 → 시계탑 익스트림 롱숏 | 시간·장소 캡션을 컷 경계에 걸침. 넓게 → 좁게(P-01) |
| 1장 중 | 도시 전경 위에 화면 밖 외침 "롤랑!!!"(가시형) → 조수 등장, 투덜대는 대사 → `아카데미 소속 조수 <마핀>` | **첫 대사가 외침**이라 정적인 풍경이 바로 깨진다. 네임플레이트는 첫 등장 컷 아래 모서리에 둔다. |
| 1장 뒤 | 탐정 등장 `아카데미 소속 탐정 <롤랑>` → 둘의 티격태격 | 관계를 대사로 보여준다(설명 나레이션 없음). |
| 2장 | 야경 와이드 컷 위 대화 "요즘은 페즐도 잘 안 나오지.." → "미스테리오(Mysterio) 그놈들도" → 해당 세력 캐릭터 컷 + `미스테리오 <모티>`, `<아이리스>` | **세력 이름을 대사에서 먼저 언급하고(영문 병기), 바로 다음 컷에서 그 세력 캐릭터를 보여준다.** 세계관 설명이 대화 속에 녹아 있다. |
| 3장 | "데모니코(Demonico)" → `데모니코 <루리>` → 검은 화면 위 큰 흰 글씨 "그 말썽쟁이 꼬맹이들도..", "귀찮은 괴도들도..", "상대하기 힘든 왕실까지..!" + 각 문구 아래 사선 컷의 캐릭터 | **열거 몽타주**: "~도.. ~도.. ~까지..!" 반복 구문 + 사선 컷으로 세력을 빠르게 훑고, 마지막에 탐정의 외침 리액션("전부 우리가 처리해야 된다는 소리 아닌가..!!")으로 웃음을 만든다. |
| 4장 | 소란한 외침들 → 검→흰 그라데이션 → 차분한 독백(따옴표가 있는 사각 박스) → "자네도 이곳에 온 이상 이야기를 써내려 가겠지." → "그럼 시작하지, 우리의.. 그리고 자네의." → 로고 | **톤 전환**: 코미디 → 차분한 초대. 그라데이션으로 분위기를 바꾼 뒤 유저를 호명한다. 독백은 말풍선 대신 사각 박스로 구분한다. |

실측(16498, 가로 1000px): 열거 몽타주 대형 문구 약 70px, 흰색 고딕 계열 굵은 글씨, 검은 배경 / 사선 컷 기울기 약 3~4°

### 5.2 StartRail (3장, 1000×8000 ×2 + 1000×4000, 흰색 ↔ 검정)

| 구간 | 내용 | 기법 |
|---|---|---|
| 1장 앞 | 흰 여백 위 대형 타이포 "청춘(靑春)" | 테마 단어 하나로 콜드 오픈. 한자 병기 |
| 1장 | "누군가는 그걸 인생에 주어진 단 한번의 축복이라고 부른다." / "그리고 누군가는 그걸 인생 최악의 저주라고 부른다." | **대구(對句) 나레이션**: 같은 구문을 반복하며 밝은 컷 ↔ 어두운 컷을 교차한다. 나레이션 박스는 사선 컷 위쪽 경계에 걸친다. |
| 1장 뒤~2장 | "누군가는 새로운 도전을 향해서 나아가고," / "누군가는 그동안 해왔던 대로 똑같이 살아가기도 한다." / "그리고 누군가는 절망한다." | 대구가 이어지면서 배경이 흰색 → 검정으로 바뀐다. 컷은 손, 발, 눈 같은 **익스트림 클로즈업 띠 컷**이다. |
| 2장 | 검은 화면 위 붉은 문구 "이게 진짜 내가 원했던 것이 맞나?" → "...." → "하지만." | 붉은 질문 → 침묵 → 단독 "하지만."으로 반전 직전에 멈춘다(T-04). |
| 2장 뒤 | 발광 흰 글씨 "그럼에도 청춘(당신)들은 나아간다." → 눈물 클로즈업 띠 컷 → 그라데이션으로 흰 배경 복귀 | **"청춘(당신)" 괄호로 독자를 테마에 겹친다.** 검정 → 흰색 = 희망 |
| 2장 끝~3장 | "그 작은 용기와 한 걸음이," → "당신의 청춘의 시작이다."(교실 창가 컷) → "지금부터 당신이 겪을 이야기는," / "그 첫 걸음을 만들어 가는 이야기." → "당신이 만들어가는," → 삼각 파편 몽타주(등장 캐릭터 전원) → 로고 + "시작의 이야기." | **2인칭 선언 → 캐릭터 전원 예고 → 로고**. 문장을 쉼표로 끊어 컷 사이에 걸쳐 놓아 스크롤을 이끈다("당신이 만들어가는," → 몽타주 → 로고). |

실측(16526, 가로 1000px): 나레이션 글자 약 40px, 굵은 명조 계열 / 나레이션 박스 약 370×150px, 테두리 약 2px / 사선 컷은 위·아래 변의 기울기가 서로 다른 사다리꼴(약 2~4°) / 컷 폭 1000px 전폭

### 5.3 우리 작품에 가져올 것 (혼합형 제안)

| 비트 | 가져올 기법 | 출처 작품 |
|---|---|---|
| ① 콜드 오픈 | **"당신은…" 2인칭 나레이션**을 흰 여백 위 큰 글씨로 시작한다. 짧게 끊은 문장. | StartRail |
| ② 세계관 | 대구 나레이션 2~3쌍으로 세계의 양면을 보여준다. 이어서 시간·장소 캡션 + 익스트림 롱숏으로 무대를 세운다. | StartRail + 탐정 아카데미 |
| ③ 위협·결핍 | 검정 전환 → 붉은 질문 → "...." → "하지만." | StartRail |
| ④ 캐릭터 | **대사로 세력·인물을 언급 → 다음 컷에서 등장 + 네임플레이트**. 3개 이상이면 "~도.. ~도.. ~까지..!" 열거 몽타주 | 탐정 아카데미 |
| ⑤ 유저 자리 | 캐릭터 간 만담 뒤 그라데이션으로 톤을 바꾸고, 캐릭터가 화면 밖의 "당신"에게 말을 건다. | 탐정 아카데미 |
| ⑥ 초대·타이틀 | 쉼표로 끊은 2인칭 문장 → 캐릭터 몽타주 → 로고 + 부제. 마지막 대사는 채팅 첫 메시지로 이어진다. | StartRail + 탐정 아카데미 |

분량 목표: 1000×8000 기준 2~4장(사용자 확정). 대략 ①② 1장, ③④ 1~2장, ⑤⑥ 1장으로 배분한다.

## 6. 우리 툴에 주는 시사점

1. **6비트 골격을 기본 템플릿으로** 두고, 작품 성격(세계관 중심 / 캐릭터 중심)에 따라 비트 비중을 조절한다. 이 프로젝트의 기본값은 5.3의 혼합형이다.
2. **⑥의 마지막 문구를 채팅 첫 메시지와 이어지게** 설계한다. 예를 들어 캐릭터가 유저에게 직접 말을 걸며 끝나면, 채팅의 첫 메시지가 그 대답이 된다.
3. 레퍼런스는 나레이션 비중이 높다. 세계관 설명이 과해지지 않도록 **비트 ②는 나레이션 박스 6~10개 이내**를 기본 한도로 둔다(directing-rules.md W-03).
4. 렌더러가 지원해야 할 요소는 spec.md 3.1의 카탈로그와 같다.
5. 레퍼런스 대부분은 인물과 배경이 합쳐진 통짜 AI 일러스트를 크롭해서 컷으로 쓴다. 따라서 에셋 요청서는 "투명 PNG 캐릭터 + 배경" 방식과 "통짜 일러스트" 방식을 모두 지원해야 한다.
