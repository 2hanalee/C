# 01. 분석: 의도, 이전 사이트, 레퍼런스

## 1. 참치의 의도 다시 쓰기

1. 라에온은 "닻이 박힌 대륙을 건너가는 이야기"다. 사이트는 정보 창고보다 여행 안내서에 가까워야 하고, 읽는 사람이 나라 하나를 지날 때마다 풍경과 사람과 위험이 함께 바뀌는 것을 느껴야 한다.
2. 이야기의 중심은 두 개의 선형 스토리다. 설정을 아무리 많이 실어도, 처음 온 사람이 "어느 이야기로 들어갈지"를 3초 안에 고를 수 있어야 한다.
3. 설정이 매우 많다(지역 17곳, 인물 약 100명, 마물 약 130종, 용어 22개, 비밀 15축). 많다는 사실 자체가 매력이 되도록, 찾기 쉽고 끝까지 읽고 싶게 만들어야 한다.
4. "세계 안의 책"이 디자인의 뼈대다. 그러나 화면을 책 모양으로 감싸는 것이 아니라, 각 구획을 그 세계의 저자가 썼다는 느낌을 목소리와 재질로 낸다. 설정집에 이미 말하는 마법서 세 권이 있으므로, 그 책들이 사이트의 안내자가 될 수 있다.
5. 책이라면 내용이 두꺼워야 한다. 지금 설정집은 마물 이름과 등급만 있고 설명이 없으므로, 기획 단계에서 보강 목록과 서식을 먼저 정해야 한다.

## 2. 블랙아웃에서 배운 것

| 구분 | 내용 | 라에온에 적용 |
|---|---|---|
| 효과 있음 | 세계 안의 물건(인사기록카드, 문서철, 도장)으로 화면을 짠 것. 장식이 아니라 "이 세계의 누군가가 만든 기록"이라는 근거가 생겼다 | 같은 원리를 책으로 옮긴다. 다만 구획마다 저자가 달라 재질도 달라진다 |
| 효과 있음 | 누를 수 있는 것에는 동사와 화살표, 누를 수 없는 것은 카드처럼 꾸미지 않기 | 그대로 쓴다 |
| 효과 있음 | 데이터 파일과 페이지 스크립트를 나눈 정적 구조, 자동 점검 스크립트 | 그대로 쓴다. 분량이 커서 더 중요하다 |
| 효과 있음 | 완결 문장 기준의 문구 손질 | 그대로 쓴다 |
| 실패 | 3단 열람 스위치. 재미가 없고 무엇이 숨었는지 몰랐다 | 스포일러는 "이야기를 어디까지 읽었나"로 연다(책갈피) |
| 실패 | 장식용 영문 겉글자(DOSSIER, ARCHIVE) | 쓰지 않는다 |
| 실패 | SVG로 그린 기호가 싸 보였다 | 책 표지, 도판, 봉인은 그림 에셋으로 만든다 |
| 실패 | 대화가 너무 길어져 토큰이 많이 들었다 | 기획 문서를 파일로 남기고 단계마다 새로 시작할 수 있게 한다 |

| 탐정아카데미19th | 사진 액자 중심 인물 | 그림을 물건(액자, 사진)에 담는 방식 | 없음 |

## 4. 결론

- 라에온의 뼈대는 "여정 지도 + 세계 안의 문헌들"이다. 여정 지도가 이야기와 지역을 묶고, 문헌들이 많은 설정을 저자별로 나눠 맡는다.
- 설정집의 말하는 마법서 세 권(마물 101종 총해록, 산적 마그히와 대해, 노바카사 연애록)이 그대로 마물 도감, 지형 도감, 인간형 마물 도감의 저자가 된다. 새 장치를 지어낼 필요가 적다.
- 인물은 모험가 길드의 직업군 급 체계가 이미 있으므로 "길드 등록부"라는 문헌으로 묶는다.
- 비밀은 봉인된 책으로, 용어집은 모든 책 뒤에 붙는 색인으로 만든다.
