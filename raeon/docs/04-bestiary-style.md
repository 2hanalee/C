# 04. 마물 도감 문체와 카드 계획

참치가 보낸 예시 카드 8장(슬라임, 리자드맨, 오우거, 미노타우르스, 블러드 스켈레톤 검사, 크라켄, 레비아탄, 균열 12생물종 《회한》)을 분석해 도감 전체의 규칙으로 정리했다.
결정 사항: 마물은 **전부** 쓴다. 설명은 길게 늘어놓는 도감 항목이 아니라, **저자가 남긴 듯한 짧은 설명**이며 마물의 격에 따라 문체가 바뀐다.

### 읽어 낸 규칙

1. **격이 낮을수록 저자가 앞에 나선다.** 약한 마물은 저자가 비웃거나 비꼬는 한마디(슬라임, 오우거)이거나, 감정 없는 사실 몇 줄(리자드맨)이다.
2. **중간 격은 도감의 목소리다.** 서식, 무기, 습성, 지능을 한다체로 짧게 적는다(미노타우르스, 블러드 스켈레톤 검사).
3. **격이 높을수록 저자가 물러나고 전설이 말한다.** SS는 이명으로 시작해 예언형 어미로 끝난다. 이름에 작은따옴표를 씌운다(‘크라켄’, ‘레비아탄’).
4. **균열 마물은 총해록이 아니라 다른 책이 말한다.** 문장 일부가 해독되지 않은 문자로 깨지고, 위험도는 "???"다.
5. 출처 줄은 책마다 다르다: 《오우거도 알아듣는 마물 101종 총해록 발췌》, 《신이 없는 세계의 신, 그리고 균열에서 발췌》.

## 2. 문체 단계표

### 함께 지킬 것

- **설정과 어긋나지 않는다.** 한 줄이라도 설정집의 사실을 벗어나면 안 된다. 예를 들어 크라켄은 설정상 "악의가 없고 호기심이 많은" 존재다. 예시의 "운명을 응시한다"는 작중 학자의 전설 해석으로 읽히므로 괜찮지만, "사람을 증오한다"처럼 쓰면 쿠라 설정과 충돌한다. 이런 경우 03 문서 방식으로 확인 표시를 단다.
- **스포일러를 넣지 않는다.** 🟡 내용(예: 진조와 선대 마왕의 꿈, 마왕화 루시아나)은 한 줄에도 넣지 않는다. 마왕화 루시아나 항목은 공개 도감에서 봉인 칸으로만 둔다.
- **띄어쓰기를 지킨다.** 예시의 "듯 합니다"는 "듯합니다"가 맞다. 카드 그림에 글자를 박으면 이런 오류를 나중에 고칠 수 없다(4장 참조).
- **총해록 말투의 일관성.** 1~2단계에서 저자가 앞에 나설 때는 합니다체를 쓴다(슬라임, 오우거). 사실 서술은 한다체다. 한 카드 안에서 섞지 않는다.

## 3. 어느 책이 맡는가

| 책 | 맡는 마물 | 수 |
|---|---|---|
| 총해록 | 비인간형 마물. 리자드맨, 오우거, 미노타우르스처럼 두 발로 서도 사람의 모습이 아니면 여기 | 101종을 목표로 맞춘다 |
| 노바카사 연애록 | 사람의 모습을 한 마물 종(라미아, 세이렌, 하피, 아라크네, 스킬라, 메두사, 발키리, 뱀파이어, 서큐버스, 구미호, 누레온나 등) | 나머지 |
| 균열 문헌 | 미확인 균열 통로, 미확인 균열 파생종, 심연의 응시자(공개), 《회한》(🟡 봉인) | 3 + 봉인 1 |

- 사다리 전체는 약 129종이다. 인간형을 연애록으로 넘기면 총해록이 100종 안팎이 되므로, 경계에 있는 종 몇 개를 조정해 정확히 101종으로 맞추는 것을 권한다. 그러면 "제1항~제101항" 번호를 그대로 쓸 수 있다. 분류 확정은 참치가 한다.
- 연애록이 맡는 종의 한 줄은 노바카사의 가락("~라네")으로 쓴다. 문체 단계표 대신 연애록 고유의 말투를 쓴다.
- 인간형 종을 총해록에서 찾으면 "그건 담당이 아닙니다." 카드가 나오고 연애록으로 넘어간다.
- 주의: 설정집은 《회한》을 9장의 🟡 스포일러로 두었다(리모스의 정체). 그래서 공개 도감의 균열 장에는 공개 마물 3종만 보이고, 《회한》 카드는 책갈피가 스토리 1의 8장에 닿기 전까지 봉인 칸으로 둔다. 예시 카드는 디자인 기준으로만 쓴다.

## 4. 카드 형식

### 4-1. 예시 카드의 구성

- 가로 3:2. 왼쪽 약 40%가 글 칸, 오른쪽 약 60%가 그림.
- 글 칸 위에서부터: 계통 문장(紋章) → 이름(큰 명조) → 영문명(일부) → 안쪽 액자(위험도와 등급) → "상세설명" → 한 줄 → 출처.
- 금색 장식 테두리와 모서리 장식, 검은 바탕.
- 계통 문장은 마물마다 다르다: 뿔 달린 해골과 월계수(일반), 소 두개골(미노타우르스), 붉은 보석 해골과 박쥐 날개(혈족 언데드), 소용돌이 나침반(균열).
- 등급 글자색: 대부분 금색, SS는 붉은색, 블러드 스켈레톤의 B는 붉은 빛, 균열의 ???는 푸른 빛.

### 4-2. 정리한 규칙

| 요소 | 규칙 |
|---|---|
| 계통 문장 | 계통별로 8개를 만든다: 짐승, 아인(서서 다니는 마물), 언데드, 혈족(노크투르나), 용과 해수, 정령과 구조물(골렘, 엘리멘탈), 마족과 마왕군, 균열 |
| 등급 색 | F~A+ 금색. S 이상 붉은색. 계통의 강조색(혈족의 붉은 빛)은 이름 글자의 빛으로만 쓰고 등급 색은 규칙대로 둔다 |
| 이름 표기 | SS 이상만 ‘작은따옴표’ |
| 영문명 | 모든 카드에 작게 단다. 데이터에 영문명 칸을 둔다. 설정집에 없는 영문명은 새로 정하고 확인 표시를 단다 |
| 출처 줄 | 책마다 고정 문구 |

### 4-3. 그림과 글자를 나누는 것을 권한다

예시처럼 그림 생성 단계에서 글자까지 넣은 카드는 보기 좋지만, 사이트에서는 세 가지 문제가 생긴다.

1. **휴대폰에서 읽을 수 없다.** 1536px 카드가 390px 화면 폭으로 줄면 본문 글자가 7px 정도가 된다.
2. **고칠 수 없다.** 띄어쓰기 하나를 고치려면 그림을 다시 만들어야 하고, 같은 그림이 다시 나오지 않는다.
3. **찾을 수 없다.** 검색, 화면 낭독기, 용어 연결이 글자를 읽지 못한다.

그래서 **그림은 글자 없이 만들고, 카드 틀과 글은 사이트가 그린다**:
- 그림: 오른쪽 60% 자리에 맞는 그림만 만든다(글자 없음, 테두리 없음). 사이트에서 3:2 카드의 오른쪽에 붙이고, 휴대폰에서는 그림을 위에, 글 칸을 아래에 쌓는다.
- 틀: 금색 테두리, 모서리 장식, 구분선, 계통 문장 8개를 에셋으로 한 번만 만든다.
- 글: 데이터 파일의 한 줄을 그대로 찍는다. 홍보용으로 예시 같은 완성 카드가 필요하면, 사이트 화면을 3:2로 찍어 이미지로 내보낸다.

이미 만든 8장은 그림 부분만 잘라 쓰거나, 글자 없는 판으로 다시 만들면 된다.

### 4-4. 시각 방향 B(낮의 양피지 지도)와의 관계

사이트 바탕은 밝은 양피지로 정했다. 검은 마물 카드는 양피지 위에 끼운 **도판**으로 둔다. 밝은 책장 위의 어두운 도판이라 대비가 강해 마물 쪽으로 눈이 간다. 지역과 인물 같은 다른 책은 양피지 재질을 그대로 쓰고, 검은 판은 마물 도감과 균열 문헌에만 쓴다.

## 6. 작성 계획

| 순서 | 할 일 | 결과 |
|---|---|---|
| 1 | 참치가 2장 단계표와 5장 견본의 말투를 승인한다 | 문체 확정 |
| 2 | 3장의 책 나누기를 확정한다(총해록 101종 맞추기) | 마물별 담당 책, 총해록 항 번호 |
