# 07. 디자인 품질 개선 마스터 프롬프트

## 0. 현재 품질 평가(1차 시안, 11월 25일)

| 항목 | 점수(5점) | 근거 |
|---|---|---|
| 첫인상 | 2 | 입장 연출이 없다. 표지가 분홍·보라 그라데이션 위의 글자뿐이라 "책을 연다"는 기대가 생기지 않는다 |
| 배경과 에셋의 조화 | 1.5 | 참치의 카드는 먹색 바탕, 금 테두리, 짙은 유화풍이다. 그런데 사이트 바탕은 파스텔 노을(새벽), 주황(사르티온), 하늘색(인물)이라 카드가 바탕에서 떠 보인다 |
| 배색 | 1.5 | 하늘 팔레트 20개, 크림 종이 6종, 금, 붉은 표시, 하늘색 링크, 장밋빛까지 한 화면에 6~8색이 겹친다. 카드 그림 자체가 색이 많으므로 바탕은 색을 빼야 한다 |
| 전환 | 1.5 | 페이지 이동과 해시 이동이 모두 툭 끊긴다. 지역마다 하늘이 바뀌는 것도 전환 없이 갑자기 바뀌어 촌스럽다 |
| 책다움 | 2 | 종이 질감과 띠는 있지만, 마물과 지형을 "책에서 펼쳐 본다"는 체험이 없다. 카드가 격자에 나열될 뿐이다 |
| 정보 구조와 기능 | 4 | 책갈피 해금, 용어 창, 데이터 연결은 잘 작동한다(점검 289화면 오류 0) |
| 읽기 편함 | 3.5 | 본문 글꼴과 줄 간격은 좋다. 띠와 칸 이름이 작고 흐리다 |

**결론:** 기능은 남기고 겉을 다시 짠다. 원인은 하나다. **에셋(카드)이 정한 색과 재질을 사이트가 따르지 않았다.**

## 1. 개선 원칙

1. **카드가 팔레트를 정한다.** 사이트 색은 카드에서 뽑는다: 먹(#100E0B), 짙은 갈색 가죽(#2A2018), 양피지(#E9DFC8), 금(#C9A45C), 그리고 위험을 뜻하는 붉은색 하나(#B8463A). 이 다섯 색 밖의 색은 쓰지 않는다. 지역의 색은 사이트가 칠하지 않고 **카드 그림이 낸다.**
2. **바탕은 어둡고 조용하게.** 하늘 그라데이션 20개를 버린다. 바탕은 먹색 하나에, 지금 보는 지역이나 장소의 카드 그림을 크게 흐리고 어둡게 깐다. 그러면 바탕과 에셋이 같은 그림에서 나온다.
3. **책은 두 층이다.** 사이트 전체는 웹 화면 그대로 두고(책 모양이 화면의 중심이 되지 않게), 마물과 지형을 볼 때만 **책 뷰어**가 열린다. 책 뷰어는 실제 책처럼 펼침면, 책장 넘김, 목차, 책갈피 끈을 가진다.
4. **전환은 하나의 문법으로.** 페이지 사이 이동은 크로스페이드(View Transitions), 책 안에서는 책장 넘김, 바탕 그림은 천천히 녹아 바뀐다. 모든 전환은 0.35~0.6초, 움직임 줄이기 설정에서는 즉시 바뀐다.
5. **입장은 책을 여는 일이다.** 닫힌 가죽 장정 → 금박 닻 문장이 빛남 → 표지가 열리며 대륙 지도 펼침면 → 사이트. 3초 안팎, 건너뛰기, 같은 방문 안에서는 다시 보이지 않는다.

## 2. 산출물

1. 디자인 캔버스(아티팩트 "Design"): 팔레트와 글꼴, 입장 연출 장면 순서, 책 뷰어(마물·지형, PC 펼침면과 휴대폰 한 쪽), 전환 문법.
2. 사이트 반영:
   - `raeon.css` 색 토큰 재정의, 하늘 팔레트 제거, 바탕 그림 층 추가
   - `assets/js/intro.js` 입장 연출
   - `assets/js/book.js` 책 뷰어(총해록, 연애록, 균열 문헌, 마그히 지형 책)
   - View Transitions와 바탕 그림 전환
3. 점검: 모든 화면 오류 0, 책 뷰어 앞뒤 넘김·목차·키보드(←→ Esc)·스와이프, 움직임 줄이기.

## 3. 완료 기준

- 한 화면에 보이는 사이트 고유색이 5색 이하다(카드 그림 제외).
- 지역 쪽 바탕이 그 지역 카드 그림에서 나온다.
- 도감과 지도에서 "책으로 보기"를 누르면 책이 펼쳐지고, 마물 133종과 장소 36곳을 책장 넘기며 볼 수 있다.
- 페이지 이동, 책장 넘김, 바탕 전환에 끊김이 없다.
- 입장 연출이 처음 방문에서 재생되고, 건너뛰기와 다시 보기가 된다.
