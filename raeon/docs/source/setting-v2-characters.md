# 라에온 설정집 v2: 인물

성별은 따로 적지 않으면 여성. 이모지가 붙은 인물은 노바카사 연애록에 실린 인간형 마물. 등급은 마물이 아닌 인물은 직업군 급(1~7급), 마물인 인물은 F~SSS. 🟡 줄은 스포일러.
참치 승인으로 빠진 이름과 오탈자를 채웠다. [확인 필요] 표시는 추정이다.
필드 순서: 종족·나이 / 등급 / 소속 / 외모 / 성격·설정 / 말투 / 관계 / 대표 대사 / 몸짓 / 용사 제도와의 거리 / 등장 / 🟡

## 5-1. 핵심 인물

### 카일 · 백섬의 용사
- 종족·나이: 인간·22세 / 등급: 기사 1급(용사) / 소속: 라에온 백섬 기사단장 / 지역: 라에온

- 성격·설정: 이 세계에서 가장 강력한 용사로 알려져 있다. 실력 하나로 고위 귀족 가문의 양녀가 되어 엘리트의 길을 밟았고, 재능 위에 누구보다 긴 수련을 쌓아 기사단장에 올랐다. 하늘이 그녀를 고른 것은 교단 성도의 신성 정원 앞에서였다. 성검에 감정을 내주며 힘을 얻고, 그 끝이 이른 죽음이라는 것을 이미 안다. 남의 버릇과 숨은 과거를 예리하게 알아채지만 짧은 의심의 말 한마디만 남길 뿐 캐묻지 않는다
- 말투: 해라체 단정문. '-다', '-나?'로 끝나는 짧은 문장만 쓰고 느낌표와 말줄임표를 쓰지 않는다. 성검에 감정을 내줄수록 감정어가 사실어로 바뀐다('무섭다' 대신 '위험하다', '기쁘다' 대신 '좋은 결과다')
- 대표 대사: "그런가." / "야영은 동쪽 비탈에 친다. 교대는 두 시간." / "네가 웃었다. 좋은 결과다. 그렇게 기억해 두겠다."
- 몸짓: 언제나 출입구가 보이는 자리에 앉고, 칼자루에서 손을 떼지 않는다
- 용사 제도와의 거리: 제도 그 자체이자 그 희생자
- 등장: 스토리 2의 중심 인물(원정대장). 스토리 1에서는 플레이어가 용사의 자리에 선다
- 🟡(스토리 2 발견 이후) 스토리 2에서 카일은 원정대를 지저국 깊은 곳에 두고 혼자 돌아오라는 명령을 받았다
